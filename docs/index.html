assistant

ローカルLLMがゲートウェイになる、デスクトップアシスタント

簡単な質問はローカルモデルだけで完結させ、手に負えない質問だけを ChatGPT / Claude / Gemini に自動転送。レスポンス速度・コスト・プライバシーを両立します。

最新版をダウンロード GitHubで見る macOS (Apple Silicon) / Windows / Linux 対応

特徴

ローカルLLM実行
node-llama-cpp によるオンデバイス推論。Apple SiliconではMetalアクセラレーションに対応。
Autoルーティング
ローカルモデル自身が「自分で答えられるか」を判定し、無理なら自動でクラウドへ転送。判定理由も表示されます。
コマンドによる強制切り替え
/local /cloud /openai /claude /gemini でその場だけプロバイダーを指定できます。
安全なAPIキー管理
OSのKeychain経由(Electron safeStorage)で暗号化保存。平文キーがrendererに渡ることはありません。
MCP対応
設定したMCPサーバーのツールを、ローカルモデル・クラウドプロバイダー共通で呼び出せます。外部AIクライアントからこのアプリ自体を操作するMCPサーバーも内蔵。
RAG(検索拡張生成)
組み込みのLanceDBと独自埋め込みモデルで、取り込んだドキュメントを踏まえた回答が可能です。
LoRAアダプタ
ローカルモデルにLoRAアダプタ(GGUF形式)を適用可能。Settingsから選択するだけです。
複数チャットセッション
会話は自動保存され、サイドバーから一覧・切り替え・削除ができます。
