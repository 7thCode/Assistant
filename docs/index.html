仕組み

Autoモードでは、ローカルモデル自身が「自分で答えられるか」を判定し、必要な質問だけを自動でクラウドへ橋渡しします。

1
メッセージを送信
ヘッダーでモード(Local / Auto / ChatGPT / Claude / Gemini)を選ぶか、/claude のようなコマンドでその1通だけ強制指定できます。
2
ローカルモデルが判定
Autoモードでは、まずローカルモデルが自分で答えられるかを自己評価。判定理由はチャット上のバッジで確認できます。
3
必要な時だけクラウドへ
手に負えない質問だけを ChatGPT / Claude / Gemini に自動転送。RAG・MCP・Skillsのツールはどちらのモードでも共通して使えます。

機能

ローカル実行とクラウド連携を軸に、知識の拡張・カスタムコマンド・自動化まで一通り揃っています。

ハイブリッド動作

ローカルLLM実行
node-llama-cpp によるオンデバイス推論。Apple SiliconではMetalアクセラレーションに対応し、ネットワーク不要で動作します。
5つの動作モード
Local / Auto / ChatGPT / Claude / Gemini をヘッダーからワンクリックで切り替え。用途に応じて即座に変更できます。
Autoルーティング
ローカルモデル自身が「自分で答えられるか」を判定し、無理なら自動でクラウドへ転送。判定理由もバッジで表示されます。
コマンドによる強制切り替え
メッセージの先頭に /local /cloud /openai /claude /gemini を付けると、その1通だけ指定プロバイダーへ送信できます。

知識・ツールの拡張

RAG(検索拡張生成)
組み込みのLanceDBと独自埋め込みモデルで、取り込んだドキュメントを踏まえた回答が可能。関連度の低い質問には注入しません。
MCP対応
設定したMCPサーバーのツールを、ローカルモデル・クラウドプロバイダー共通で呼び出せます。外部AIクライアントからこのアプリ自体を操作するMCPサーバーも内蔵。
Skills(独自コマンド)
/名前 メッセージで呼び出せる独自コマンドをアプリ内で新規作成・編集・削除。決まった指示をプロンプトに注入できます。
位置情報Function Calling
ローカルモデルが必要に応じてFunction Callingで現在地(IPベース・市区町村レベル)を取得。天気や近隣情報の質問にそのまま使えます。
LoRAアダプタ
ローカルモデルにLoRAアダプタ(GGUF形式)を適用可能。Settingsからファイルを選択するだけで有効になります。

安全性・運用

安全なAPIキー管理
OSのKeychain経由(Electron safeStorage)で暗号化保存。平文キーがrendererに渡ることはありません。
複数チャットセッション
会話は自動保存され、サイドバーから一覧・切り替え・削除ができます。作業ごとにセッションを分けて管理可能です。
