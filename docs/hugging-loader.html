Hugging-loader

Hugging Face Hub の GGUF モデルを検索し、パラメータ数・量子化タイプ・サイズで見比べて、そのままダウンロードできるデスクトップアプリです。llama.cpp 系のアプリ(Assistant を含む)で使うモデルを探す用途に向いています。

最新版をダウンロード GitHubで見る
人気順に検索
gguf タグの付いたリポジトリを、ダウンロード数の多い順に検索。text-generation などタスクでも絞り込めます。
パラメータ数で絞り込み
「1B未満」〜「90B以上」の区分で絞り込み。値は GGUF メタデータから取得し、取れない場合のみモデル名から推定します。
量子化タイプを判定・選択
ファイル名から Q4_K_M や IQ3_M などを判定して表示し、複数種類を選んで絞り込めます。ファイルサイズも一覧で比較できます。
分割・並列ダウンロード
HTTP Range で最大6分割して並列取得。数GBのモデルでも速く、途中で止めても再開でき、進捗表示とキャンセルに対応します。
取得済みの管理
保存先フォルダに取得履歴を記録し、ダウンロード済みのファイルを一覧上で判別・削除できます。履歴はモデルフォルダと一緒に移動できます。
Assistantと連携
保存先に Assistant のモデルフォルダを指定すれば、ダウンロードした GGUF を Assistant でそのまま選択して使えます。
